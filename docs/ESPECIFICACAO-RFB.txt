RFBSTUDIO — ESPECIFICAÇÃO COMPLETA
======================================================================
Status: concepção. Produto: RFBStudio. Segmento: Personalização de produtos 3D. Slogan: Escolha, visualize e transforme.

O PROBLEMA
Vendedores de produtos customizados precisam explicar variantes e mostrar como a personalização afetará o resultado e o preço.

QUEM USA
Consumidores, marcas de produtos customizados e designers.

PROPOSTA DE VALOR
Mudar cores e acessórios altera modelo e preço mantendo configurações ao recarregar.

IDENTIDADE DO DESIGN
Produto 3D central, barra de opções à direita, configurações e preço vivos.

STACK
React + TypeScript + Vite; Cloudflare Workers / Static Assets; Firebase Auth / Firestore; ferramentas opcionais conforme módulo.

ORIENTAÇÃO DE CUSTO
Modelos leves e assets estáticos cabem em demo; render cloud e modelos pesados elevam custo.

ARQUITETURA ESPECIALIZADA
Three.js + React Three Fiber; Firestore para configurações; assets 3D versionados na Cloudflare.

RISCO PRINCIPAL
Modelos 3D exigem autoria/licença; otimizar GLB, textura e LOD para mobile.

======================================================================
JORNADA PRINCIPAL E CASOS ALTERNATIVOS
======================================================================
1. Escolher produto.
2. Carregar modelo.
3. Alterar cor/material.
4. Recalcular preço.
5. Salvar configuração.
6. Enviar orçamento.

Em qualquer etapa: usuário não autenticado, sem permissão, conexão interrompida, item removido, limite excedido, edição concorrente, tentativa duplicada e retomada são fluxos previstos.


======================================================================
MÁQUINA DE ESTADOS
======================================================================
inicial -> personalizando -> salva -> orcada -> enviada -> aprovada
Cada transição deve definir ator permitido, pré-condição, pós-condição, efeito externo, política de retry e log; setar transições ilegais como erro de domínio.
